# Lenchi Studio — приложение мастера

Мобильное приложение для мастера ногтевого сервиса: календарь записей, клиенты, услуги, напоминания и финансы.
Сделано на Expo (React Native), работает на Android и iPhone.

## Запуск на телефоне

1. Установите на телефон **Expo Go** из Google Play или App Store.
2. В терминале:
   ```bash
   cd mobile
   npm install
   npx expo start
   ```
3. Отсканируйте QR-код из терминала: на Android — в Expo Go, на iPhone — камерой.
   Телефон и компьютер должны быть в одной Wi-Fi сети. Если не подключается — `npx expo start --tunnel`.

## Что умеет

- **Календарь** — записи по дням, свободные промежутки, проверка пересечений.
- **Клиенты** — карточка, история визитов, сумма и средний чек, звонок / WhatsApp / Telegram.
- **Услуги** — прайс с длительностью; изначально заполнен ценами из ГномГуру.
- **Напоминания** — готовый текст по шаблону, отправка в WhatsApp или Telegram без SMS.
- **Свободные окошки** — собирает пост со свободным временем для Telegram-канала.
- **Финансы** — выручка за неделю / месяц / год, средний чек, неявки, популярные услуги.
- **Резервная копия** — выгрузка всех данных в JSON.

Данные хранятся локально на телефоне (SQLite).

## Структура

```
src/app/          экраны (Expo Router)
src/components/   общие элементы интерфейса
src/db/           схема базы и запросы
src/utils/        даты, сообщения, расчёт свободного времени
```
