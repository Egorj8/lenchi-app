# План и идеи

## Сделано
- [x] MVP: записи, клиенты, услуги (прайс ГномГуру), напоминания, свободные окошки, финансы
- [x] Этап 1: календарь (день / неделя / месяц, сетка по часам), импорт из контактов, номера в формате +код
- [x] Этап 2: корзина с «Вернуть», копия файлом / в папку, восстановление из файла и текста, автокопии
- [x] Личные дела: шаблоны, категории, весь день, повторы, «занимает время», «Сделано»
- [x] Своя иконка и тёмная заставка; Android-эмулятор для проверки сборок

## Следующее — Этап 3. Приложение само приносит клиенток
- [ ] **«Пора на коррекцию»**: клиентка была 3–4 недели назад и не записана → сообщение со свободным окошком одной кнопкой
- [ ] **Утренняя сводка** (локальное уведомление в 9:00): сколько записей, кому не отправлены напоминания
- [ ] **Дни рождения**: поле в карточке, напоминание, готовое поздравление
- [ ] **Лист ожидания**: при отмене записи предложить время тем, кто ждёт

## Этап 4. Удобство каждый день
- [ ] Клиентка из последнего звонка (журнал звонков; работает в APK, в Google Play почти запрещено)
- [ ] Фото работ в карточке клиентки
- [ ] Расходы (материалы, аренда) → прибыль
- [ ] Отпуск и особые часы на отдельные дни

## Этап 5. Онлайн-запись — полная замена ГномГуру
- [ ] Страница записи для клиенток в стиле лендинга
- [ ] Записи сразу появляются в приложении; данные в облаке (бесплатный сервер, например Supabase — регистрирует пользователь)
- [ ] После этого — перевести кнопку на лендинге с ГномГуру на свою запись

## Хвосты
- [ ] Перейти на Expo SDK 58 (57 был нужен только для старого Expo Go)
- [ ] Пульсация кнопки «Отправить копию» — коротко, а не постоянно (батарея)
- [ ] Не проверено руками на эмуляторе: правка/удаление серии повторяющегося дела; отправка копии в Telegram / Google Диск (на эмуляторе нет этих приложений)
- [ ] Веб-версия устарела (без этапов 1–2 и дел) — обновить, когда вернёмся к iPhone

## Отложено
- iPhone: Apple Developer ($99/год) → TestFlight; бесплатный вариант — веб-версия «на экран Домой»
- Публикация в Google Play ($25 разово)

## Идеи из разбора ГномГуру (брать лучшее, не перегружать)
- Чего нет ни у кого: «пора на коррекцию», утренняя сводка, автоподбор из листа ожидания, без платных стен (корзина бесплатно)
- Есть у ГномГуру и стоит взять: клиент из звонка, лист ожидания, поздравления, расходы
- Не брать (для салонов): сотрудники, ресурсы, «сеть клиентов», товары, журнал изменений
- Слабости ГномГуру: перегруженное меню, лабиринт настроек, сбои синхронизации и мессенджеров, поддержка только в будни, цена
